# OP2020M 线外啮合工位操作手册

该PC只有一个啮合工位，无PLC，一次处理一个产品。

1. 打开检测软件和MES上位机，在消息页查看OP2020M面板。
2. 扫描产品SN，无需打开扫码弹窗。
3. 等待“进站OK”后，对同一件产品进行啮合检测并保存一次结果。
4. 程序等待新增MDB写完，读取数值并自动提交MES出站。
5. 显示“出站OK”后移走本件，扫描下一件。

进站、出站始终使用扫码SN，不使用MDB文件名或表中的二维码。处理期间重复扫码不会覆盖当前件。

MES失败后排除问题，点击“重试原任务”；出站重试使用原SN和已读取的数据。请求超时时，先核实MES是否已收到，避免重复提交；程序不会自动重复发送。

等待数据时不要补存旧件、复制旧文件或重测其他件。目录不存在、文件占用或数据尚未写完时会显示错误，处理后程序继续读取。

本版不再保存和恢复未完成任务。应在本件出站成功后再关闭、切型或重启程序；异常重启后先人工处理当前件的MES状态，再开始下一件。旧版人工核实和异常结束按钮已移除。

MDB的Result只保存在本件数据中，暂不参与判断。出站OK表示MES接收成功。

OP2020M扫码时调用FeedingCheck代替CheckIn，返回结果写入`SetHelper.resultModel[0].Result1`（OK/NG），扫码SN写入`CheckInSN`。FeedingCheck成功后才等待MDB自动出站；失败重试仍调用FeedingCheck。MES接口配置使用第一个工位的FeedingCheck地址。
