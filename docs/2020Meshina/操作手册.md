# 2020Meshina 线外啮合工位操作手册

## 正常操作

1. 打开啮合检测软件与MES上位机，进入上位机“消息”页面，确认啮合站面板无初始化错误。
2. 确认工位只有当前一件产品，用扫码枪扫描产品SN。无需先打开扫码弹窗。
3. 等待面板提示“进站OK，可以开始啮合”。进站失败或“待核实”时停止操作，联系技术人员。
4. 对刚扫码的同一件产品进行齿轮啮合检测，并让检测软件正常保存结果。一次扫码只检测、保存一次。
5. 上位机检测到新MDB文件并读到数据后，会自动向MES提交出站。文件写入过程中等待数秒属于正常情况。
6. 看到“出站OK，可以扫描下一件”后，移走本件，扫描下一件。

当前产品未完成时再次扫码不会覆盖当前SN。进出站均使用扫码枪扫描的SN，检测文件名和文件中的二维码不用于替换SN。

## 异常处理

| 面板状态 | 处理方法 |
| --- | --- |
| 等待本次检测MDB | 确认已对当前件完成检测并保存到规定目录；不要重新扫码其他产品。 |
| MDB占用、必填字段为空、空表 | 等待检测软件完成写入。持续异常时联系技术人员；不要复制旧结果冒充本次结果。 |
| 多个候选MDB或多条记录 | 停止测量与保存，联系技术人员核实正确记录。不得自行删除文件或任意选择最新结果。 |
| MES进站/出站失败 | 排除MES提示的问题后点击“重试原任务”。重试仍使用原SN；出站重试使用已经保存的原检测数据。 |
| 进站/出站结果未知、待核实 | 联系技术人员查询MES当前SN的实际记录。不得因为超时就认定失败并重复提交。 |
| 驱动、目录、配置或任务保存异常 | 停止操作，联系技术人员。不得删除任务恢复文件来解除锁定。 |

## 操作约束

- 一次只处理一件，必须等本件出站OK后再扫描下一件。
- 不要在等待出站期间补存旧产品、复制历史MDB或额外重测。
- 不要先检测后扫码；上位机只匹配扫码之后的新文件。
- 软件重启后先检查恢复任务，继续处理原件，不能直接换件。
- 如需放弃本件，由技术人员先处理MES状态、停止设备测量和所有延迟保存，再使用“异常结束本件”。移走本件后才能重新扫码。
- 本期仅上传数值，MDB的Result只留存，不做本地合格判定；面板“出站OK”表示MES接收成功。
