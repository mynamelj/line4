# MDB 只读测试

独立 WPF 程序，.NET Framework 4.8（与上位机一致），x86。窗口始终置顶。

- 默认目录：`D:\齿轮双面啮合仪检测系统\统计`，可在窗口内修改。
- 启动即读取，每2秒重新读取，也可关闭自动刷新后手动读取。
- 只扫描目录顶层，按最后修改时间选择最新 `.mdb`，同时间按创建时间、文件名排序。不要求扫码。
- 每张用户表显示在独立页签，显示所有列和行；仅执行 SELECT，不移动或修改 MDB，不调用 MES。
- 使用与上位机相同的 `Mode=Read`。自动选择本机已注册的32位 ACE 12、ACE 16、Jet 4驱动，也可手动指定。
- 错误显示异常类型、错误码和原始消息。独占锁无法绕过，自动刷新时会继续尝试。文件大小/时间检查无法保证生产软件已提交全部业务数据，本工具仅用于查看。

构建：`dotnet build mdbReadTest.csproj -c Release`

运行：`bin\Release\net48\mdbReadTest.exe`。目标机需要 .NET Framework 4.8 和32位 Access/Jet驱动；不需要安装新版本 .NET SDK。部署时复制整个输出目录。

查看提供的样本：把界面目录临时改为 `D:\Backup`（读取该目录最新的 MDB）。
